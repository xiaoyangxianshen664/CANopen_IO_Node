# 阶段 1：PC 基础和 CAN 帧抽象

日期：2026-09-16。

## 目的与实现

建立独立于硬件的帧结构、节点上下文、发送回调和接收地址分类入口。按阶段进度表，本阶段不包含对象字典、NMT 状态机、Heartbeat、SDO 或 PDO 数据处理。

新增 `co_types.h`、`co_core.h`、`co_core.c`，使用 C11；源文件仅包含自身头文件、stdint.h 和 stddef.h。没有硬件/RTOS 依赖。

## 验证环境与结果

Windows，MinGW GCC 15.2.0，Ninja，Release，编译启用 -Wall -Wextra -Wpedantic -Werror。

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

配置、编译成功；4/4 测试通过，0 失败。

| 测试组 | 覆盖与预期 |
|---|---|
| core_frame | NULL 拒绝；ID=0、0x7FF 和 DLC=0、8 接受；ID=0x800、UINT32_MAX 和 DLC=9、255 拒绝；扩展/远程/FD 帧拒绝 |
| core_init | NULL 上下文/回调拒绝；Node-ID=1、127 接受，0、128、255 拒绝；失败不改原配置；状态为 Initialization |
| core_tx | 8 字节完整传递；空数据帧可提交；非法帧不调用回调；忙/失败原样返回且不自行重试 |
| core_routing | 遍历 1～127 个节点、全部 11 位非零 ID，只有本节点 0x600+ID、0x200+ID 被分类；遍历 NMT 目标 0～255，只接受广播和本节点；NMT DLC 必须为 2；不改变节点状态或发帧 |

具体向量例：Node-ID=1 时，0x601 分类为 SDO，0x201 分类为 RPDO1，0x602/0x202/0x181/0x281/0x701 忽略；0x000、DLC=2、数据 01 00 或 01 01 分类为 NMT，01 02 忽略。这里只测试路由，不执行命令。
