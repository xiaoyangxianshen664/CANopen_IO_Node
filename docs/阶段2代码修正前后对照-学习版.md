## 6. co_od.c：按类型解释数值后检查

位置：[co_od.c](C:/Users/lolbo/CANopen_IO_Node/canopen/src/co_od.c:125)，当前第 125～134 行。

新增两步：

```c
if (value < entry->min_value || value > entry->max_value)
{
    return CO_ERR_OD_VALUE;
}
```

**修改后（当前实际代码）：**

```c

    /* 按16位补码解释有符号值，再进行范围检查。 */
    if (entry->type == CO_OD_INTEGER16 && value >= 0x8000)
```

## 11. update_inputs：保留原始输入接口，转换后存入对象

位置：[co_device_od.c](C:/Users/lolbo/CANopen_IO_Node/canopen/src/co_device_od.c:166)，当前第 166～177 行。

这里只改最后两条AI赋值。输入检查仍是0～4095，DI不变；检查全部通过才更新，失败不改半组。

单极性AI编码：`bit15=0（正号），bit14..3放12位ADC数据，bit2..0=0`，因此左移3位。不是简单左移4位；那会把高半量程的符号位置1。这个乘8公式是本项目单极性量程约定，不是规范给所有ADC规定的统一公式。

|原始ADC|对象值|低字节在前|
|---|---|---|
|0|0x0000|00 00|
|1|0x0008|08 00|
|2048|0x4000|00 40|
|4095|0x7FF8|F8 7F|

上位机需要原始值时除以8。read_value()不需要改，它仍把当前整数拆成小端字节。

**修改前：**

```c
co_status_t co_device_od_update_inputs(co_device_od_t *device, uint8_t di,
                                       uint16_t ai1, uint16_t ai2)
{
    if (!ready(device))
        return CO_ERR_ARGUMENT;
    if (di > 15 || ai1 > 4095 || ai2 > 4095)
        return CO_ERR_OD_VALUE;
    device->fields[DI_SLOT].value = di;
    device->fields[AI1_SLOT].value = ai1;
    device->fields[AI2_SLOT].value = ai2;
    return CO_OK;
}
```

**修改后（当前实际代码）：**

```c
co_status_t co_device_od_update_inputs(co_device_od_t *device, uint8_t di,
                                       uint16_t ai1, uint16_t ai2)
{
    if (!ready(device))
        return CO_ERR_ARGUMENT;
    if (di > 15 || ai1 > 4095 || ai2 > 4095)
        return CO_ERR_OD_VALUE;
    device->fields[DI_SLOT].value = di;
    device->fields[AI1_SLOT].value = (uint32_t)ai1 << 3; /* 正号位保留，12位有效值左对齐 */
    device->fields[AI2_SLOT].value = (uint32_t)ai2 << 3;
    return CO_OK;
}
```



## 12. set_error：保留位和通用错误位

位置：[co_device_od.c](C:/Users/lolbo/CANopen_IO_Node/canopen/src/co_device_od.c:193)，当前第 193～201 行。

0x40=0100 0000，只检查bit6；0x60=0110 0000，检查bit5和bit6。bit6由301保留，bit5在这个401设备规范中保留。

最后的三目表达式意思是：error非零时保存error|1，补通用错误bit0；error为0时保存0。例：传0x10保存0x11；传0x20或0x40被拒绝；传0清除错误。本函数仍不发送EMCY。

**修改前：**

```c
co_status_t co_device_od_set_error(co_device_od_t *device, uint8_t error)
{
    if (!ready(device))
        return CO_ERR_ARGUMENT;
    if ((error & 0x40u) != 0)
        return CO_ERR_OD_VALUE;
    device->fields[ERROR_SLOT].value = error;
    return CO_OK;
}
```

**修改后（当前实际代码）：**

```c
co_status_t co_device_od_set_error(co_device_od_t *device, uint8_t error)
{
    if (!ready(device))
        return CO_ERR_ARGUMENT;
    if ((error & 0x60u) != 0)
        return CO_ERR_OD_VALUE;
    device->fields[ERROR_SLOT].value = error ? (error | 1u) : 0u;
    return CO_OK;
}
```
