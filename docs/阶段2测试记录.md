# 阶段 2 对象字典基础层测试记录

日期：2026-09-18  
分支：`stage2-object-dictionary`

## 本阶段实现

- `co_od.h/.c`：对象条目、类型长度、访问权限和读写回调接口；
- `(Index, Sub-index)` 对象查找；
- UNSIGNED8、UNSIGNED16、UNSIGNED32 的长度校验；
- 只读对象拒绝写入；
- 写入数据长度和数值范围校验；
- PDO 参数只能在 `CO_NMT_PRE_OPERATIONAL` 状态写入；
- 通过 `user` 指针把对象存储或硬件访问隔离在回调中。

## 测试命令

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
