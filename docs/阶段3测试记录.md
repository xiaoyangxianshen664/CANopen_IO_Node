# 阶段3：NMT 与 Boot-up

2026-09-23：完成纯C实现，源码学习尚未开始。无HAL、FreeRTOS或实机验证。

## 实现入口

- `co_nmt.h/.c`：绑定节点和设备对象表、发送Boot-up、处理五种NMT命令。
- `co_device_od_reset()`：通信复位恢复通信区可变数据；节点复位恢复全部可变数据。保留身份、固定配置和对象表指针绑定。
- `test_co_nmt.c`：模拟发送、状态通知、命令与复位测试；已接入CMake/CTest。

调用顺序：`co_init()` → `co_device_od_init()` → `co_nmt_init()` → `co_nmt_bootup()`。接收帧交给 `co_nmt_receive()`，内部复用阶段1分类器；不需要调用者先分类。

Boot-up发送回调返回CO_OK后进入Pre-op；忙或失败则保持Initialization，调用者再次调用bootup重试。成功只代表传输层接受提交，不代表总线ACK。重复调用已完成的bootup返回CO_IGNORED，不重发。初始化中忽略NMT命令。

状态通知回调在状态改变后调用，绑定时也通知Initialization。应用通过它执行安全物理输出、清理后续服务计时和队列；不得重入协议API。通信复位保留DO命令，不代表允许物理输出继续驱动。真实GPIO安全输出仍在硬件集成阶段验证。未来服务需在Initialization通知时清理状态；Heartbeat/PDO/EMCY尚未实现。
