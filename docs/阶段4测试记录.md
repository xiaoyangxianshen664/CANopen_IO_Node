# 阶段4：Heartbeat Producer 测试记录

日期：2026-09-29

## 范围

本阶段在PC纯C环境实现Heartbeat Producer，不接入HAL、FreeRTOS或真实CAN总线。`co_hb_process()`由调用者提供经过的毫秒数，读取对象 `0x1017:00` 并在到期时提交Heartbeat帧。

## 实现

- `co_hb_init()`：绑定节点和设备对象表，记录 `0x1017:00` 的写入次数。
- `co_hb_process()`：周期性读取Heartbeat配置，累计时间并发送 `0x700 + Node-ID`、DLC=1、数据为当前NMT状态。
- 周期为0时关闭Heartbeat；Initialization状态不重复发送Boot-up的 `0x00`。
- 周期对象重写（包括同值重写）会重启计时；发送忙或失败时保留到期状态，允许后续重试。
